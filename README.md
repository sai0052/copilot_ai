# CodePilot AI

> Autonomous AI Coding Agent for analyzing, fixing, reviewing, and testing software projects.

CodePilot AI is a full-stack AI-powered coding agent that can inspect a local software repository, understand the project structure, analyze problems, make code changes, run tests, and report the results through a web interface.

It is designed as a practical AI engineering project demonstrating LLM integration, agentic workflows, repository analysis, tool execution, automated testing, and full-stack development.

---

## 🚀 Features

### 🤖 Autonomous AI Coding Agent

- Understands natural-language coding tasks
- Analyzes repository structure
- Searches source code
- Reads relevant files
- Plans changes before implementation
- Modifies project files
- Runs tests
- Analyzes test failures
- Reports execution results

### 🛠️ Task Modes

CodePilot AI supports multiple task types:

- **Implement** — Implement a new feature
- **Code Review** — Analyze existing code
- **Explain** — Explain code and architecture
- **Issue** — Diagnose and fix bugs

### 📂 Repository Management

- Register local repositories
- Scan project directories
- View repository structure
- Search source files
- Load different local projects
- Inspect project files

### 🧪 Automated Testing

The agent can:

- Detect available test frameworks
- Run project tests
- Analyze test failures
- Use test results to guide fixes
- Verify changes after implementation
